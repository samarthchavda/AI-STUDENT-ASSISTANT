## What We Can Legally Use

### ✅ SAFE (Public Domain / Fair Use)
1. **Algorithm Concepts**: Sorting, searching, dynamic programming, etc.
2. **Problem Patterns**: Array manipulation, tree traversal, graph algorithms
3. **Company Names**: Amazon, Google, Microsoft, TCS (factual information)
4. **Difficulty Levels**: Easy, Medium, Hard (generic classification)
5. **Topics**: Arrays, Strings, Trees, Graphs, DP (standard CS terminology)
6. **Time/Space Complexity**: O(n), O(log n) (mathematical notation)

### ❌ CANNOT USE (Copyrighted)
1. **Exact Problem Descriptions**: Word-for-word from other platforms
2. **Specific Examples**: Identical input/output from other sites
3. **Platform Names**: In marketing or as if affiliated
4. **Problem IDs**: Direct references to other platform's numbering
5. **Trademarked Terms**: Platform-specific terminology
